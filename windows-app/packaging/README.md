# Windows packaging

`windows-app\build.ps1` builds the release binary with
`cargo build --release -p billflow` and stages this layout under
`windows-app\packaging\staged\BillFlow\`:

```
BillFlow\
  billflow.exe    # release binary
  icon.ico        # from assets/icon.ico
  LICENSE.txt     # repo LICENSE, or a placeholder generated by build.ps1
  assets\         # source icon assets
```

The script runs as a normal user and does not require administrator rights.

## Two output options

### 1. Portable ZIP (always produced)

`windows-app\packaging\BillFlow-portable.zip` contains the `BillFlow` folder.
Extract it anywhere and run `billflow.exe`. Nothing is written outside the
folder except the application database in `%APPDATA%\BillFlow\billflow.sqlite3`.
This is the simplest way to distribute the app; there is no installer and no
uninstall step beyond deleting the folder.

### 2. Inno Setup installer (optional)

If the Inno Setup 6 compiler (`iscc`) is on `PATH`, `build.ps1` also compiles
`inno-setup.iss` into `BillFlow-1.0.0-setup.exe` in this directory. The installer:

- is 64-bit and installs per-user (`{localappdata}\BillFlow`), so it needs no
  administrator rights;
- installs `billflow.exe`, `icon.ico`, `LICENSE.txt` and `assets\`;
- creates a Start Menu shortcut and an Uninstall shortcut;
- offers an optional desktop shortcut as a install-time task;
- provides an uninstaller through Windows' Apps & features.

`inno-setup.iss` expects the staged paths above. If the repository has a
`LICENSE` file, `build.ps1` copies it into the staged folder; otherwise it
writes a clearly marked placeholder — replace it with the real project license
before distributing a build.

WiX Toolset is another optional installer framework and is not used here. An
installer of either kind is **not required**: the portable ZIP is fully
functional on its own.

## Runtime notes

Windows 10/11 (64-bit) is the target. The Rust binary carries no Node.js,
Python, browser or database-server dependency. All data is local in
`%APPDATA%\BillFlow\billflow.sqlite3`.
